## Exercise boundary

The external adversary operated from a separate AWS account/network and reached the lab only through public Internet services. Attacker commands and ground truth were kept separate from the SOC and IR investigations until defender decisions were recorded.

Scenario 01 remained reconnaissance-only: no exploitation, credential attacks, destructive actions, persistence, malware or denial of service.
